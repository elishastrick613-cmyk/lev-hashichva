# לב השכבה — שכבה ז׳ תשפג״ז

אפליקציה בעברית למעקב בכל שיעור ובתפילה, עם סיכום שבועי.

## הפעלה ראשונה

1. פרסום `firestore.rules` בפרויקט Firebase `lev-hashicva`.
2. העלאת קבצי התיקייה למאגר GitHub. ב־Settings → Pages לבחור Deploy from a branch, ענף main ותיקיית ‎/(root)‎.
3. פתיחת הקישור שנוצר לאחר השלמת הפרסום ב־GitHub Pages.
4. הרשמה באפליקציה עם כתובת המנהל `elishastrick613@gmail.com`, בחירת סיסמה ואימות המייל באמצעות הקישור שנשלח.
5. חזרה לאפליקציה ולחיצה על ״אימתתי את המייל״. חשבון המנהל מקבל גישה לפי המייל המאומת.
6. מורים נוספים נרשמים ומאמתים מייל. המנהל מאשר אותם בלשונית ״אישור מורים״.

מומלץ לוודא ב־Firebase Authentication → Settings → Authorized domains ששם האתר המפורסם מאושר לפני בדיקת קישורי האימות ואיפוס הסיסמה.

## נתונים והרשאות

- נתוני ההדגמה הישנים אינם מועלים ל־Firebase. האתר מתחיל עם כיתות ז׳1–ז׳4 וללא תלמידים.
- נדרש מייל מאומת. מורה שממתין לאישור אינו יכול לקרוא תלמידים או הערכות.
- כל מורה מאושר יכול לקרוא את כלל התלמידים והערכות השבוע שנבחר.
- כל מורה יוצר הערכות תחת המזהה שלו. כתיבה להערכה של מורה אחר חסומה בשרת, גם עבור המנהל.
- תלמיד חדש נשמר עם שם, כיתה ומזהה המורה שהוסיף אותו. אין פעולת מחיקה או עריכת תלמיד בגרסה הזו.
- המסך האישי והכיתתי מציגים את ההערכה של המשתמש המחובר. הסיכום השבועי כולל את ההערכות מכל המורים, עם שם המורה בפירוט.
- בתפילה יש שלושה מדדים; בשיעורים חמישה. היעדרות אינה נכללת בחישוב האחוזים.
- הנתונים נקראים בזמן אמת לשבוע שנבחר בלבד. אין שמירת נתוני תלמידים ב־localStorage.
- השהיית מורה חוסמת קריאה וכתיבה של נתוני השכבה. נתונים שכבר נצפו או הועתקו אינם ניתנים למשיכה ממכשיר של משתמש.

הקובץ `firebase-config.js` מכיל את הגדרות אפליקציית ה־Web. הרשאות לנתונים נקבעות בכללי Firestore; אין להעלות למאגר מפתח שירות או סיסמאות.

## בדיקת קבלה לפני שימוש אמיתי

- מנהל יכול להיכנס רק לאחר אימות המייל.
- מורה חדש אינו יכול לקרוא תלמידים לפני אישור.
- אחרי אישור, מורה יכול להוסיף תלמיד ולשמור הערכת שיעור ותפילה.
- במכשיר נוסף הנתונים מופיעים בסיכום השבועי.
- מורה שני יכול לראות את ההערכה של הראשון בפירוט, אך אינו יכול לשנות אותה.
- אחרי השהיית גישה, המורה אינו יכול לקרוא או לכתוב נתונים.
- יש לבדוק מסך אישי וכיתתי בטלפון והחלפת שבוע.
